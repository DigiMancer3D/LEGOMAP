❔ Getting started

Tap the large + to add a set. Tap a card to see progress, edit it, and start a clock. Hold the + for 2.1 seconds to open Settings. Tap your circular profile picture to see the gallery; hold it for 1.8 seconds to change the picture.

Timer modes: Practice and Play do not enter official trails. Record and Record + Play do. Play adds a target based on your personal best. Tap Save splice to pause the work until a later session; tap Finish build only when the set is finished.

Data: Saved automatically to this browser on this device, using IndexedDB where available. Use Export .lemap regularly to keep a portable backup. Shared cards and leaderboards remove private notes, photos, storage locations and profile identity by default.

Links: IB v2 links are small self-contained snapshots. They are not automatic live synchronization. A clean-program link requires the HTML to be hosted at a public HTTP(S) address; downloading the clean file always works.

Inventory: Set copies and their piece counts are tracked separately from pieces currently built. Adjust missing pieces if needed. Official top times are only completed recorded attempts.
